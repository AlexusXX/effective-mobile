Объяснить различия в инициализирующих выражениях для `heavy1` и `heavy2`.

> `heavy1 = container.extract();`
> 
> В этом случае вызывается метод extract() у уже созданного объекта container, который возвращает локальный объект 
> типа Heavy. Этот объект копируется (или перемещается), чтобы инициализировать heavy1.
> 
> `heavy2 = generate().extract();`
> 
> Здесь сначала вызывается generate(), что создает временный объект Container. Затем вызывается extract() на этом 
> временном объекте. Возвращаемый локальный Heavy также копируется (или перемещается) для инициализации heavy2.

Дополнить (ничего не удаляя) Heavy и Container так, чтобы устранить копирование там, где это возможно
> 1. Метод `extract` теперь возвращает константную ссылку на item, а не его копию.
> ```c++
>	const Heavy &extract() const
>	{
>		return item;
>	}
>```
> 2. В функции main возвращаемая ссылка присваивается в ссылочный тип Heavy&, что предотвращает копирование здесь
> ```c++
>	auto &heavy1 = container.extract();
>	auto &heavy2 = generate().extract();
> ```
> Как итог, конструктор копирования Heavy ни разу не вызывается.
